# 会員規則

<span style="font-weight: 400;">この規則は、定款第3章に基づき、一般社団法人日本インスティテューショナル・リサーチ協会（以下「本協会」）の会員に関して必要な事項を定めたものである。</span>

## <span style="font-weight: 400;">会員資格</span>

- <span style="font-weight: 400;">インスティテューショナル・リサーチ（IR）に従事するまたは関心を持つ大学教職員、学生、民間企業人など高等教育関係者。</span>
- <span style="font-weight: 400;">我が国のIRの発展と推進に賛同する者。</span>

## <span style="font-weight: 400;">会員種類</span>

- **正会員（個人）**<span style="font-weight: 400;">：本協会の目的及び事業（定款第2章）に賛同する個人。</span>
- **賛助会員（個人または団体）**<span style="font-weight: 400;">：本協会の目的及び事業（定款第2章）に賛同し、本協会の活動に協力又は支援する</span><span style="font-weight: 400;">個人または団体</span><span style="font-weight: 400;">。</span>
- **名誉会員**<span style="font-weight: 400;">：本協会の活動及びIRの普及に貢献し又は功労があった者として理事会が推薦する個人又は団体。</span>

## <span style="font-weight: 400;">会費</span>

- <span style="font-weight: 400;">正会員（個人）　年3,000円</span>
- <span style="font-weight: 400;">賛助会員（個人または団体） 年10,000円（4名まで個人登録が可能）</span>

<!-- -->

- <span style="font-weight: 400;">本協会の事業年度（毎年4月1日から翌年3月31日まで、定款第7章第32条）を会費の会計年度としする。</span>
- <span style="font-weight: 400;">会費は毎年4月に請求を行い、4月末を入金の締め切りとする。入会者は入会申込後に協会が請求を行い、1ヶ月以内の入金を締め切りとし、</span><span style="font-weight: 400;">年度の途中で入会した場合も全額納付するものとする。</span>
- <span style="font-weight: 400;">会費納付が2年以上ない場合は、総会で当該会員の除名を行う（定款第10条(1)）。</span>

## <span style="font-weight: 400;">会員特典</span>

- <span style="font-weight: 400;">Slackへの登録</span><span style="font-weight: 400;">（1会員につき1アカウント）</span>
- <span style="font-weight: 400;">研究会への参加（研究会Zoom情報の提供、Slackで確認可能）</span>
- <span style="font-weight: 400;">MJIR参加費の割引（2025年度から）</span>

## <span style="font-weight: 400;">入会のプロセス</span>

- <span style="font-weight: 400;">入会のお申し込みは随時、本協会ウェブサイトの入会申込（</span><span style="font-weight: 400;">{{ '/registration/' | relative_url }}</span><span style="font-weight: 400;">）の入会フォームより受け付ける。</span>
- <span style="font-weight: 400;">入会申込を受付後、理事会の承認をもって会員（入会）となります。なお、正会員（個人会員）と賛助会員のプロセスは以下のとおりとなる。</span>

### <span style="font-weight: 400;">正会員（個人）</span>

1.  **入会希望者**<span style="font-weight: 400;">：入会フォームには以下の項目全てに入力が必要。</span>
    - <span style="font-weight: 400;">氏名</span>
    - <span style="font-weight: 400;">氏名ふりがな</span>
    - <span style="font-weight: 400;">所属機関</span>
    - <span style="font-weight: 400;">ORCID-id（</span><span style="font-weight: 400;">ORCID-idは </span>[<span style="font-weight: 400;">https://orcid.org/</span>](https://orcid.org/)<span style="font-weight: 400;"> から検索できます。</span><span style="font-weight: 400;">ORCID-idをお持ちでない方は登録。登録方法の動画は</span>[<span style="font-weight: 400;">こちら</span>](https://www.youtube.com/results?search_query=ORCID+id+%E7%99%BB%E9%8C%B2)<span style="font-weight: 400;">。）</span>
    - <span style="font-weight: 400;">メールアドレス</span>
    - <span style="font-weight: 400;">連絡先住所</span>
    - <span style="font-weight: 400;">連絡先郵便番号</span>
2.  **本協会**<span style="font-weight: 400;">：入会申込受付後、会員担当理事から入会希望者へ会費支払いに関する情報を案内する。</span>
3.  **入会希望者**<span style="font-weight: 400;">：1ヶ月以内に会費を支払う。</span>
4.  **本協会**<span style="font-weight: 400;">：会員担当理事は会費支払いを確認の上、一ヶ月ごとに理事へ報告する。</span>
5.  **本協会**<span style="font-weight: 400;">：理事による入会承認をもって、入会希望者は正会員（個人会員）となる。会員担当理事から入会希望者へ入会承認を通知する。</span>

### <span style="font-weight: 400;">賛助会員（個人または団体）</span>

1.  **入会希望者**<span style="font-weight: 400;">：入会フォームには以下の項目全てに入力が必要。</span>
    - <span style="font-weight: 400;">機関名</span>
    - <span style="font-weight: 400;">機関名ふりがな</span>
    - <span style="font-weight: 400;">ROR（</span><span style="font-weight: 400;">Research Organization Registry、</span>[<span style="font-weight: 400;">https://ror.org/</span>](https://ror.org/)<span style="font-weight: 400;"> で貴学のROR-idを検索できる）</span>
    - <span style="font-weight: 400;">申込代表者氏名</span>
    - <span style="font-weight: 400;">申込代表者氏名ふりがな</span>
    - <span style="font-weight: 400;">申込代表者メールアドレス</span>
    - 申込代表者　<span style="font-weight: 400;">ORCID-id（</span><span style="font-weight: 400;">ORCID-idは </span>[<span style="font-weight: 400;">https://orcid.org/</span>](https://orcid.org/)<span style="font-weight: 400;"> から検索できます。</span><span style="font-weight: 400;">ORCID-idをお持ちでない方は登録。登録方法の動画は</span>[<span style="font-weight: 400;">こちら</span>](https://www.youtube.com/results?search_query=ORCID+id+%E7%99%BB%E9%8C%B2)<span style="font-weight: 400;">。）</span>
    - <span style="font-weight: 400;">機関連絡先住所</span>
    - <span style="font-weight: 400;">機関連絡先郵便番号</span>
2.  **本協会**<span style="font-weight: 400;">：入会申込受付後、会員担当理事から入会希望者へ会費支払いに関する情報を案内する。</span>
    - <span style="font-weight: 400;">Slack登録は1アドレスのみ。</span>
    - <span style="font-weight: 400;">研究会参加およびMJIR参加費割引（2025年から）は4名まで。</span>
    - JAIRからのメール連絡は、機関窓口担当者（入会後は、申込代表者は機関窓口担当者となる）にするので、機関内者への連絡は、機関窓口担当者からお願いします。
3.  **入会希望者**<span style="font-weight: 400;">：1ヶ月以内に会費を支払う。</span>
4.  **本協会**<span style="font-weight: 400;">：会員担当理事は会費支払いを確認の上、一ヶ月ごとに理事へ報告する。</span>
5.  **本協会**<span style="font-weight: 400;">：理事による入会承認をもって、入会希望者は賛助会員（個人または団体）となる。会員担当理事から入会希望者へ入会承認を通知する。</span>
